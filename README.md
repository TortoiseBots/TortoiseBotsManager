# TortoiseBots Manager

[![Latest release](https://img.shields.io/github/v/release/Sagiroth/TortoiseBotsManager?label=release&logo=github)](https://github.com/Sagiroth/TortoiseBotsManager/releases/latest)
[![Support on Ko-fi](https://img.shields.io/badge/Ko--fi-support-FF5E5B?logo=ko-fi&logoColor=white)](https://ko-fi.com/sagiroth)
[![Discord](https://img.shields.io/badge/Discord-join-5865F2?logo=discord&logoColor=white)](https://discord.gg/FT2rZcXm3)

The in-game control panel (`/tbm`) for [TortoiseBots](https://github.com/Sagiroth/TortoiseBots) on **Tortoise WoW 1.18.1** (Vanilla 1.12 / `11200`). Log your alts in as bots, group them, and issue orders quietly via addon messages instead of typing `.bot` commands.

> [!IMPORTANT]
> Requires a server running [TortoiseBots](https://github.com/Sagiroth/TortoiseBots). New to TortoiseBots? Start with its [Getting Started](https://github.com/Sagiroth/TortoiseBots/blob/main/docs/play/getting-started.md) guide.

## Install

1. Download `TortoiseBotsManager.zip` from the [latest release](https://github.com/Sagiroth/TortoiseBotsManager/releases/latest).
2. Extract it into `World of Warcraft/Interface/AddOns/TortoiseBotsManager` (not nested twice).
3. Restart the client fully (WoW loads new addon files only on a full restart, not `/reload`) and run `/tbm`.
